# MAKE UP UI 风格规则

更新：2026-10-12。依据：当前网站基础样式及用户明确的灰色背景要求。

- 整体使用黑、白、中性灰。页面底色为白色，卡片需要填充时默认用中性浅灰 `#f5f5f5`。
- 新增界面不自行加入绿色、黄绿色、橄榄色背景，也不把偏绿的灰色当作中性灰。
- 套餐或主要操作通过深色文字、边框、按钮和信息层级突出，不靠绿色底色区分。
- 错误、警告等真实状态可沿用已有语义颜色；这些颜色不作为装饰背景。
- 基础样式和变量见 `src/styles.css`：白色背景、`--ink` 深色文字、`--muted` 次要文字、`--line` 分隔线。沿用现有字体和组件。
- 外部网站只用于参考布局、信息组织和交互，不自动引入对方品牌配色；历史参考笔记不覆盖本规则。
- 新增或修改 UI 前读取本文件；以用户最新明确要求为准。检查实际桌面、手机页面的颜色、可读性和横向溢出。
