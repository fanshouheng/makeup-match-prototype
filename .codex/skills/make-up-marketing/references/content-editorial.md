# MAKE UP 内容编导参考

## 使用边界

本参考把公开编导方法转成 MAKE UP 可执行的内容检查表。它不代表平台规则，不预测爆款，也不替代产品证据、用户原话、账号后台和最新官方说明。

第三方内容只作为研究输入。不要复制无许可证 Skill、转录或抓取数据，不冒充真人创作者，也不采用固定流量池、固定发布时间、爆款保证或粉丝量变现门槛等未经验证的主张。

## 决策顺序

`产品待验证问题 -> 目标用户场景 -> 单一内容使命 -> 可公开证据 -> 核心判断 -> 开头承诺 -> 视听证明 -> 单一 CTA -> 数据复盘`

上游没有答案时先补证据，不先优化标题、发布时间或剪辑技巧。

## 单条内容任务书

| 字段 | 必须回答的问题 |
| --- | --- |
| 产品问题 | 这条内容要帮助验证核心价值、邀请闭环还是 Plus 交付？ |
| 目标用户 | 哪类女性在什么具体情境下需要妆容参考？ |
| 单一使命 | 本条优先负责触达、校准期待、促使体验、收集反馈还是验证付费？ |
| 核心判断 | 用户看完后只需要改变哪一个判断？ |
| 可公开证据 | 能展示哪段自有产品流程、匿名聚合数据或已授权材料？ |
| 开头承诺 | 前 10 秒承诺什么，正文在何处兑现？ |
| 视听分工 | 画面证明什么，口播解释什么？ |
| 单一 CTA | 用户看完只做哪一个动作？ |
| 验收信号 | 哪个匿名指标或用户原话决定继续、调整或停止？ |

## 内容结构

默认使用四段，不要求机械套用固定句式：

1. **场景与冲突**：说出用户正在经历的具体困难，不攻击用户，也不制造外貌焦虑。
2. **核心判断**：说明 MAKE UP 能缩小参考范围，不能保证找到“同一张脸”或专业效果。
3. **可见证明**：展示选图、浏览器本地分析、结果页或公开的匿名聚合数据；隐藏照片、面部比例、账号身份和私有记录。
4. **单一动作**：只要求体验、反馈、访谈或 Plus 申请中的一个动作。

## 画面与口播

- 画面负责展示产品页面、用户动作、处理边界和结果路径。
- 口播负责解释选择、因果、限制和当前未知项。
- 不让字幕、口播和画面重复同一句信息。
- 可露脸，但不把创始人故事放在女性用户问题之前。
- 只使用自有、生成或明确获得营销授权的素材。

## 平台处理

- 小红书与抖音都不预设只能使用某一种内容体裁。
- 同一母题可以改编为视频或图文，但要按平台内数据分别判断。
- 前几条只建立账号基线；不要跨平台直接比较绝对播放量。
- 每轮只优先调整一个变量：选题、开头、证据、体裁或 CTA。
- 发布前检查当前官方规则、商业合作标识和账号健康提示；平台判断标注核验日期。

## 复盘问题

1. 进来的是否是需要妆容参考的女性，而不是泛 AI 或开发者受众？
2. 用户是否理解“参考范围”而不是“精准同脸”？
3. 用户有没有完成本条唯一动作？
4. 新反馈改变了哪个产品判断？
5. 下一条只改哪个变量？

播放量只说明触达，不足以证明匹配价值、付费成立或平台限流。反馈者符合率也只能描述主动反馈者，不能外推到所有结果用户。
